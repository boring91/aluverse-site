# Rules
---

## Rules for development
* Use bun
* Never use `interface` always use `type`
* Never use `any` always defined types
* Never set return types to functions (unless absolutely necessary)

## Rules for SEO when generating content
* Write high-quality, original content that answers user questions
* Target specific keywords using tools like Google Keyword Planner, Ahrefs, or Ubersuggest
* Aim for search intent — match your content to what users are looking for
* Update content regularly to keep it fresh
